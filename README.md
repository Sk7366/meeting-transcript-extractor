# 🚀 AI Meeting Transcript Action Extractor

> 🧠 Convert messy meeting conversations into clear, actionable insights using AI.

---

## 🌟 What It Does

Automatically extracts from any meeting transcript:

- ✅ Action Items  
- 👤 Owners  
- 📅 Deadlines  
- 🎯 Confidence Scores  

Built for Meta × Hugging Face Hackathon with a focus on accuracy + reliability.

---

## 🔥 Key Highlights

- 🧠 LLM-Powered Understanding – captures context, not just keywords  
- 🛡️ Fail-Safe System – rule-based fallback ensures no crashes  
- 📊 Interactive UI – real-time results + charts  
- 🎤 Voice Input – speak your transcript  
- 📅 Smart Deadlines – understands “tomorrow”, “EOW”, etc.  

---

## 🏗️ Tech Stack

- Backend: FastAPI  
- Frontend: HTML + JS  
- AI: OpenAI  
- Charts: Chart.js  
- Deployment: Hugging Face Spaces  

---

## ⚙️ How It Works

1. Input transcript (text/voice)  
2. AI + rules extract tasks  
3. Outputs structured actions with owner, deadline & confidence  
4. Visualized instantly in UI  

---

## 🧪 Example

Input:  
“Prepare budget by Friday. Design team finish wireframes by EOW.”

Output:  
- Budget — Finance — Friday  
- Wireframes — Design — End of Week
